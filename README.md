# BookHub Bot 📚

Telegram бот для обмена книгами с функцией поиска, сохранения поисков и управления заявками на обмен.

**Версия:** 1.1 — С онбордингом и улучшенной логикой поисков! 🎉

## Возможности

### Пользовательские функции
- ➕ **Добавить книгу** - Опубликовать свою книгу для обмена, продажи или подарка
- 🔍 **Поиск** - Найти книги по названию или автору
  - 🆕 **Умная логика поисков** - Поиск сохраняется только если вы его не завершили
- 📚 **Каталог** - Просмотреть все доступные книги
- 🔎 **Ищут** - Увидеть популярные поиски других пользователей
- 📖 **Мои книги** - Управлять своими опубликованными книгами
- 🔔 **Мои поиски** - Сохранённые поиски и уведомления
- 🤝 **Заявки** - Управление заявками на обмен
- 🚩 **Жалоба** - Пожаловаться на нарушителя
- 🎓 **Первый запуск** - Интерактивное обучение для новых пользователей

### Администраторские функции
- 📊 **Статистика** - Общая статистика по пользователям и книгам
- 📚 **Книги** - Управление опубликованными книгами
- 👥 **Пользователи** - Управление пользователями (бан, удаление)
- 🚩 **Жалобы** - Просмотр жалоб от пользователей
- 🔎 **Поиски** - 🆕 Управление поисками (исправление опечаток, удаление спама)
- 📣 **Рассылка** - Отправка сообщения всем пользователям

## Установка

### Требования
- Python 3.8+
- pip

### Шаги установки

1. **Клонируйте или скачайте проект**
```bash
cd "c:\Users\User\Desktop\Telegram bots\Kitob bot"
```

2. **Установите зависимости**
```bash
pip install -r requirements.txt
```

3. **Настройте .env файл**
Откройте `.env` и замените:
- `YOUR_BOT_TOKEN_HERE` - Токен вашего бота от BotFather (@BotFather в Telegram)
- `YOUR_ADMIN_ID_HERE` - Ваш Telegram ID (получить можно у @userinfobot)

Пример:
```
BOT_TOKEN=123456789:ABCdefGHIjklmnoPQRstuvWXYZ
ADMIN_IDS=123456789,987654321
```

4. **Запустите бота**
```bash
python bot.py
```

## 🆕 Новое в версии 1.1

### 1. Интерактивное обучение для новых пользователей
Первый запуск бота включает приветственное сообщение с тремя опциями:
- 📖 **Быстрое обучение** - 5-шаговый интерактивный тур по всем функциям
- ➕ **Добавить книгу** - начните сразу с добавления своей первой книги
- ⏭️ **Пропустить** - перейти в главное меню

Туториал объясняет как добавлять книги, искать, обмениваться и отправлять заявки.

### 2. Умная логика сохранения поисков
Теперь поиски сохраняются умнее:
- Если вы **нашли нужную книгу в поиске** и выбрали её → поиск **НЕ** сохраняется
- Если вы **не нашли** нужную книгу → поиск сохраняется автоматически
- Если вы вернулись без выбора → поиск сохраняется

Это означает, что в списке "Ищут" появляются только реальные потребности, и люди, добавляющие новые книги, получат уведомления только по актуальным поискам!

### 3. Управление поисками в админке
Администраторы теперь могут контролировать список поисков:
- Исправлять опечатки и грамматические ошибки
- Удалять спам-запросы и некорректные поиски
- Видеть количество пользователей, сохранивших каждый поиск

## Использование

После запуска бота напишите в Telegram `/start` для начала работы.

### Основные команды

- `/start` - Начало работы
- `/help` - Справка
- `/cancel` - Отмена текущей операции
- `/admin` - Админ-панель (только для администраторов)
- `/stats` - Статистика
- `/broadcast` - Рассылка сообщения всем пользователям

### Администраторские команды

- `/ban_USER_ID` - Заблокировать пользователя
- `/unban_USER_ID` - Разблокировать пользователя
- `/delete_user_USER_ID` - Удалить пользователя
- `/delete_book_BOOK_ID` - Удалить книгу
- `/edit_book_BOOK_ID название | автор | формат | город | состояние` - Редактировать книгу

## Решение проблем

### Ошибка: "Переменная BOT_TOKEN не задана"
- Убедитесь, что создан файл `.env`
- Проверьте, что `BOT_TOKEN=` содержит правильное значение

### Ошибка: "Бот уже запущен в другом окне"
- Закройте все другие экземпляры бота
- Удалите файл `bot.instance.lock` если он остался

### Бот не отвечает
- Проверьте интернет-соединение
- Убедитесь, что BOT_TOKEN правильный
- Проверьте логи в консоли

## Безопасность

- ⚠️ **Никогда** не коммитьте файл `.env` в git
- Храните BOT_TOKEN в безопасности
- Используйте сильные пароли для БД если планируете её переносить
- Регулярно проверяйте жалобы пользователей
